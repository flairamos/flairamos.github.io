02 ABOUT ME A little context

Backend by craft.
Product by heart.

比起“把功能做出来”，我更关心系统能否在真实世界里稳定运行、持续演进。 从业务建模到部署上线，我习惯把整条链路想清楚。

我是 flairamos，一名后端工程师。日常工作围绕 Java 与 Go 展开：设计接口、梳理业务模型、处理数据流，并让服务在真实流量下保持稳定。

前端方面，我了解 Vue，能够完成页面与 API 的联调，也愿意从用户体验反推后端设计。熟悉 Linux 环境，理解从需求分析、系统设计、编码测试，到容器化部署、上线监控与持续迭代的完整开发链路。Docker 有基础使用经验，正在持续深入云原生与自动化部署。

比起堆叠功能，我更在意代码的可读性、边界是否清晰，以及半年后还能不能轻松维护。好的后端应该安静、可靠，并且在需要的时候容易理解。
